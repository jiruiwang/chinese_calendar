# 川象曆：中曆0419—0485年

静态分年日曆网站，共67年。每年一個JS数据文件和一個轻量HTML入口，全部年份共用`js/calendar.js`与`css/calendar.css`。

## 顯示规则

- 中曆年、西曆年一律使用四位字符。
- 日曆下格通常顯示`MM-DD`；西曆日期为`01-01`时只顯示四位西曆年，例如`0221`。
- 日曆正文节气只使用日頁的“平氣”列。定氣仍保存在JS数据中，但不参与顯示。
- 弹窗不顯示君主，只顯示國號、年號纪年、月、日和曆法。
- 年份下拉选擇後直接跳转。

## 文件结构

- `index.html`：0419—0485年目录
- `years/419.html`—`years/485.html`：67個年份入口
- `data/419.js`—`data/485.js`：67個年份数据文件
- `js/calendar.js`：共用顯示与弹窗逻辑
- `css/calendar.css`：共用样式
- `source/川象曆_0419-0485_日表.xlsx`：当前Google“日”頁的0419—0485年数据
- `source/川象曆_0401-0500_年表.xlsx`：当前Google“年”頁
- `scripts/build-calendar-data.py`：重新生成全部年份JS

## 重新生成

```bash
python scripts/build-calendar-data.py
```

## 本地预览

```bash
python -m http.server 8000
```

然後访问`http://localhost:8000/`。

## 目录頁檢索

目录頁提供两种檢索方式：

1. **纪年檢索**：可输入中曆年、西曆年、年干支或年號，例如 `0440`、`0220`、`庚子`、`黄初元年`。
2. **朝代檢索**：按東漢、曹魏、蜀漢、孫吴、西晉分组浏览对應年份。政权交替年份可同时出现在两個朝代分组中。


## 目录卡片格式

- 纪年檢索和朝代檢索使用完全相同的年份卡片。
- 桌面宽度下每行顯示五张卡片。
- 卡片右侧按“國號＋年號”逐行左对齊。
- 年號顯示时删除括號及括號内说明；搜索仍可匹配完整年號内容。


## 國號合並顯示

同一张年份卡片中，连续属于同一國號的多個年號只在第一行顯示一次國號；國號发生变化时才再次顯示。


## 目录卡片字號

目录卡片右栏的國號和年號字號增大为13px。


## 君主檢索

目录頁新增第三個“君主檢索”標签。君主名单从各年每日正朔数据自动汇总；可按姓名搜索，並顯示该君主对應的全部中曆年份。结果卡片与纪年、朝代檢索格式一致。

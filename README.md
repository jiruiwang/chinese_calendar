# 中國歷朝正朔日曆

靜態分年日曆網站，包含中曆0001—2131年；其中0001—0500年資料由指定Google表格重讀重製，0501年以後沿用既有資料並與前段連續銜接。

## 本版修正

- 全部2131個年份頁統一使用同一套HTML、CSS與彈窗腳本。
- 0001—0500年資料即使未附帶`dayIndex`，也會由共享腳本即時建立索引，點擊任一日期均可開啟彈窗。
- 彈窗統一顯示中曆、西曆、國號、國君、年號、月、日、曆法；事件日另顯示改曆、新君、改元及出典。
- 年頁右側年號標題在「元日西曆」下方空一整行後開始。
- 0500年「下一年」正確連到0501年；0501年「上一年」正確連回0500年。
- 0500年末為西曆0281-02-05，0501年元日為0281-02-06，日期連續。
- 朝代檢索移除與「西漢」重複的「漢」卡片；西漢補全為中曆0015—0228年，凡214年。
- 全站目錄文字統一作「目録」。

## 文件結構

- `index.html`：紀年與朝代／國君檢索。
- `years/1.html`—`years/2131.html`：統一格式的年份入口。
- `data/1.js`—`data/2131.js`：各年日曆資料。
- `data/index-data.js`：目録檢索資料。
- `js/calendar.js`：全部年份共用的日曆與彈窗邏輯。
- `js/index.js`：目録檢索邏輯。
- `css/calendar.css`：全部頁面共用樣式。

## 本地預覽

```bash
python -m http.server 8000
```

瀏覽器開啟 `http://localhost:8000/`。
